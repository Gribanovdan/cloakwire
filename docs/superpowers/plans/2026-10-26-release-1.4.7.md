# Cloakwire 1.4.7 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, sign, and publish Cloakwire v1.4.7 for Windows, Android, and macOS with the verified per-app routing repair, current `main` features, and multilingual release notes.

**Architecture:** Keep the existing Tauri/Android/macOS release pipeline. Commit source and version metadata before the macOS stage because that stage packages `git archive HEAD`; keep local SDK copies, build outputs, and credentials out of Git.

**Tech Stack:** React/TypeScript, Rust/Tauri 2, Android/Kotlin, PowerShell release scripts, remote macOS build host, GitHub Releases.

## Global Constraints

- Release version is exactly `1.4.7`; tag is `v1.4.7`.
- Changelog languages: English, Russian, Simplified Chinese.
- Do not commit `artifacts/`, `dist-release/`, generated Android assets, native binaries, or signing keys.
- Do not replace dependencies or rebuild already verified artifacts unnecessarily.
